Troubleshooting domain connections

Updated June 2026
Back to Getting Started

Here are the common causes for domain incompatibility and how to fix them:

1. Incompatible DNS Setup (Most Common) 

  • Duplicate Records: You cannot have multiple A Records or CNAME records for the same subdomain.
  • Conflict with Existing Site: If your domain is currently pointed to another host (Wix, Kajabi, etc.), those old records can conflict with Alvéya.
  • Fix: Remove old A Records or CNAME records at your DNS provider (GoDaddy, Namecheap, etc.) and only have the ones provided by Alvéya

2. DNS Propagation Delays 

  • DNS changes can take up to 24–48 hours to propagate globally.
  • Fix: Wait 24 hours, or use a tool like DNSChecker.org to see if your domain is properly pointing to sites.ludicrous.cloud (for landing pages) or the IP provided in Alvéya

3. Root Domain vs. Subdomain Issues

  • Using the root domain (e.g., example.com) instead of a subdomain (e.g., go.example.com or www.example.com) can cause issues.
  • Fix: It is recommended to use a subdomain for best performance. 

4. Non-Supported Domain Providers

  • Some registrars (e.g., restricted versions of Wix or Squarespace) do not allow the necessary DNS flexibility required by Alvéya.
  • Fix: Use Cloudflare, GoDaddy, or Google Domains, which are known to be fully supported. 

5. Domain Already in Use

  • A domain can only be connected to one Alvéya sub-account at a time.
  • Fix: Check if the domain is already attached to another Alvéya account. 

6. SSL Configuration Errors

  • If your domain shows a "Not Private" or "SSL Error," it's likely that the SSL certificate hasn't been issued yet, or there is a DNS conflict.
  • Fix: Ensure your DNS is set to only one record type (either A or CNAME) and wait for the SSL to auto-generate (up to 24-48 hours). 

Recommended Troubleshooting Steps

  1. Use Cloudflare: Transfer your DNS management to Cloudflare for the fastest and most reliable setup.
  2. Verify via Domain Connect: If you use a major provider (GoDaddy, Cloudflare), use the automatic "Authorize" feature in Alvéya to avoid manual errors.
  3. Use In-App Support: Use the "Troubleshoot This Issue" link in the Alvéya domain settings if the system detects a conflict.
