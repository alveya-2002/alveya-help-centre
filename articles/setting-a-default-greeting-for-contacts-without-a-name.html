Setting a Default Greeting for Contacts Without a Name

Updated June 2026
Back to Email Marketing

When a contact is imported with only an email address and no first name on file, your email greeting can end up reading "Hi ," which looks unfinished and unprofessional. This guide covers two ways to handle it — a one-line fix that works for most people, and a more flexible setup using Conditional Sending if you want full control over your greeting text.

Before you start:  This guide applies to email campaigns and broadcasts built inside the Alvéya email editor. You will be working inside a specific email — not in global settings.

Option 1 — The Simplest Fix (One Line, No Extra Setup)

The quickest solution does not require Conditional Sending at all. Just write your greeting like this:

Hey there {{contact.first_name}},

Here is why it works: if the contact has a first name saved, the email reads “Hey there Sarah,” — warm and personal. If the name field is empty, the merge field simply disappears and the email reads “Hey there,” — which still sounds natural and intentional.

No extra blocks. No conditions. Just one line that handles both situations gracefully.

💡  This is the approach we recommend starting with. It is quick, it works, and it reads well for most practitioners. If “Hey there” suits your tone, you are done right here.

Option 2 — Conditional Sending (For a Different Greeting Style)

If “Hey there” does not suit your tone — or you want to use a completely different greeting for contacts without a name — Conditional Sending gives you that flexibility. It takes a few extra minutes to set up, but lets you choose exactly what each contact sees.

How it works

Rather than one greeting line, you create two separate greeting blocks in your email:

  • Block A shows the personalised greeting — but only if the contact has a first name saved.
  • Block B shows your chosen fallback — but only if the first name field is empty.

Alvéya checks each contact at send time and shows only the block that applies to them. Neither group ever sees a blank or broken greeting.

Step 1 — Add your personalised greeting block

  • Open your email in the Alvéya email builder.
  • Add a text block where you want your greeting to appear.
  • Type your personalised greeting, including the name merge field:

    • Hi {{contact.first_name}},

  • In the content block’s sidebar, find and enable the Conditional Sending toggle.
  • Under Set your conditions, configure the following:
  • Custom field: First Name
  • Condition: Is Not
  • Value: leave this blank

    • This tells Alvéya to show this block only when the First Name field is not empty — i.e. when the contact actually has a name saved.



    💡  The Value field being blank is intentional. You are not filtering by a specific word — you are simply checking whether the field has any content at all.

    Step 2 — Add your fallback greeting block

  • Add a second text block directly below (or in the same position as) your first block.
  • Type your fallback greeting — the one that will show when no name is available:

    • Hi there,

  • Enable the Conditional Sending toggle on this block as well.
  • Condition: Is

    •  

    This tells Alvéya to show this block only when the First Name field is empty.

    💡  You can use any fallback text that suits your brand. “Hello,”, “Dear friend,” or “Hi lovely,” all work — just make sure it reads naturally without a name following it.

    Step 3 — Preview and test

  • Use the Preview feature in the email builder to check how your email appears.
  • Test with a contact who has a first name saved, and again with a contact who does not.
  • Confirm that each contact sees only the correct greeting block — not both.

    • ⚠️  Always preview before sending. If both blocks appear for the same contact, double-check your conditions — one block should use “Is Not” (blank) and the other should use “Is” (blank).

    Things to Keep in Mind

  • Each content block can only hold one Conditional Sending condition. You cannot stack multiple field conditions within a single block.
  • This setup applies per email — you will need to configure it in each template or campaign where you want the fallback to work.
  • Conditional Sending works for any custom field, not just First Name. Use the same approach for Company, Location, or any field that might sometimes be empty.
