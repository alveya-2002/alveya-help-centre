Website Settings

This tutorial walks through the main settings that apply at a website level in Alvéya. These settings control how your site is structured, tracked, secured, and displayed, and they apply across the entire website rather than to individual pages. Page specific settings are covered in a separate tutorial below.

Use this guide to understand where key website level controls live and when they should be configured.

Page Settings

Page settings in Alvéya are applied individually to each page. This means settings do not automatically carry across your website unless a page has been duplicated. When using templates, you’ll need to review and update the settings on each page to ensure everything is configured correctly.
