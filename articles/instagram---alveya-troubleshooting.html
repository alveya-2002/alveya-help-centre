Instagram ↔ Alvéya Troubleshooting

Updated June 2026
Back to Integrations

1. Account Type Issues

  • Make sure your Instagram account is set to Business or Creator — not a personal profile. If it's personal, convert it to Professional in Instagram settings.

2. Facebook Page Not Linked

  • Your Instagram Business profile must be connected to a Facebook Page or Creator Profile. The permissions to manage your Instagram profile are granted to Alvéya through Facebook — this is a requirement from Meta (which owns Instagram).
  • If using the Facebook-linked method, make sure Instagram is connected to the correct Facebook Page.

3. Admin Access Problem

  • Your Facebook profile must have admin or full control of the Page connected to your Instagram. Without this, Alvéya won't be able to access your account.

4. Permissions Not Fully Granted

  • If you previously denied some permissions during setup, you need to remove Alvéya from Facebook Business Integrations and reconnect — making sure to allow all permission scopes this time.

5. Instagram DM Access Not Enabled

  • To enable DM access for Alvéya, go to your Instagram profile → Settings → Privacy → Messages → Connected Tools, and toggle on "Allow Access to Messages."

6. Facebook Integration Not Connected in Alvéya

  • If Instagram actions and triggers aren't appearing in your workflows, check whether your Facebook account is actually integrated. Go to Settings → Integrations tab inside Alvéya to verify and connect it.

7. Wrong Connection Method

Alvéya offers two methods — make sure you're using the right one:

  • Direct Instagram Integration — does NOT require connecting a Facebook Page during setup in Social Planner. You authenticate only with Instagram.
  • Facebook-Linked Integration — requires explicitly connecting a Facebook Page inside Social Planner. This is required if you need legacy features or view-count analytics.

8. Wrong Navigation Path

  • For Messenger/DM automation: go to Settings → Integrations → Connect under Facebook & Instagram inside Alvéya, log in to Facebook, choose your Facebook Page (the one connected to Instagram), then click Connect Facebook & Instagram and hit Sync Leads.

9. Lead Ads Not Showing Up

  • For Instagram Lead Ads, navigate to Marketing → Ad Manager → Activate Ads Manager → Connect Facebook inside Alvéya and select the correct Facebook Page before setting up any campaigns.

10. Using ManyChat as a Bridge (Advanced)

  • If you're routing Instagram DMs/comments through ManyChat to Alvéya, make sure you explicitly map all fields (like tags or email) inside the Alvéya action block in ManyChat — it only sends data you explicitly configure in its own settings block.

Quick Checklist Before Reconnecting:

  • Instagram is a Business or Creator account
  • Instagram is linked to the correct Facebook Page
  • You have Admin access on that Facebook Page
  • All permissions accepted during Alvéya auth
  • "Allow Access to Messages" is ON in Instagram settings
  • Facebook integration is active under Alvéya Settings → Integrations
