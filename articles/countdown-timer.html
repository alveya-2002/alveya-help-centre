Create a Countdown Timer in Alvéya™

Updated June 2026
Back to Email Marketing

Countdown timers help build anticipation and encourage action — whether you’re promoting an event, a special offer, or a limited-time booking window.

In Alvéya™, you can create timers in two ways:

  • From Marketing → Countdown Timers (for reusable, global timers), or

  • Inside the Page Builder (for single-page countdowns).

Option 1: Create a Global Countdown Timer (Recommended)

This option gives you the most flexibility — you can choose between Fixed, Dynamic, and Recurring timers, and reuse them across multiple pages or emails.

Step 1: Open the Countdown Timer Tool

  • From your Alvéya™ dashboard, go to Marketing → Countdown Timers.

  • Click + Create Countdown Timer.

Step 2: Choose the Timer Type

When creating your timer, select from three types:

  • Fixed Timer → counts down to a specific date and time (e.g. Offer ends Friday at midnight).

  • Dynamic Timer → counts down individually for each contact based on when they first visit the page or trigger the campaign.

  • Recurring Timer → repeats automatically on a schedule (daily, weekly, or monthly).

💡 Use Fixed for launches, Dynamic for evergreen funnels, and Recurring for ongoing weekly offers or appointment windows.

Step 3: Configure Your Timer Settings

  • Enter a clear Timer Name (e.g. Spring Sale Countdown).

  • Set your start and end time (or duration, if using Dynamic).

  • Choose what happens when time runs out:

    • Redirect visitors to another page (e.g. “Waitlist” or “Closed” page).

    • Display a message like This offer has ended.

    • Hide the timer completely.

  • Select your timezone to make sure the countdown aligns with your audience or location.

Step 4: Customise Your Timer Design

  1. Adjust your colour scheme, font style, and alignment to match your brand.

  2. Preview your timer on-screen to confirm everything looks consistent.

  3. Click Save.

Step 5: Embed Your Timer

After saving, Alvéya™ generates an embed code you can use anywhere.

  1. Copy the provided embed code.

  2. Open your Funnel or Website page editor.

  3. Add a Custom Code block where you want the timer to appear.

  4. Paste the code and click Save.

💡 Any edits you make to this global timer will automatically update everywhere it’s embedded.

Option 2: Add a Countdown Timer Inside the Page Builder

If you just need a simple countdown for a one-off page or offer, you can add a countdown element directly in the page builder.
This version is limited to a single fixed end date/time and doesn’t include Dynamic or Recurring options.

Step 1: Open the Page Builder

  1. Go to Sites → Funnels or Sites → Websites.
  2. Choose your funnel or site and click Edit Page on the page you want the timer to appear on

Step 2: Add a Countdown Element

  1. Click the “+” to add an element and search for Countdown in the search bar
  2. Drag it into your layout — for example, above your “Book Now” button or under your headline.

Step 3: Set Your End Date and Time

Timer Settings

  • Float: choose alignment (left, center, or right).

  • End Date: select the exact date you want the timer to end.

  • End Time: choose the specific time the countdown will finish.

  • Language (Translate): select your preferred language for time labels.

  • Time Zone: set the correct timezone for your audience.

 

Expire Actions

    • Expire Action: choose what happens when the countdown reaches zero.

      • Redirect to URL (e.g. a “Waitlist” or “Closed” page)

      • Hide Countdown

      • Show Text Message

    • Redirect URL: if you’re redirecting, enter the destination link (e.g. /thank-you).

Step 4: Customise the Design

Colour Settings

  • Colour: sets the timer number colour.

  • Label Colour: sets the text colour for days, hours, minutes, and seconds.

Style the Timer

Click the Styles tab to adjust spacing, borders, or alignment.

You can match the timer’s appearance with your brand by using your primary colour and preferred fonts.

Step 5: Save and Test

  1. Click Save in the top-right corner.

  2. Click Preview to ensure the countdown displays correctly and redirects (if applicable).

  3. Adjust time or colours as needed.

💡 If you’re testing the redirect, set the countdown to end in a few minutes to confirm the behaviour works as expected.

FAQS

Q: Can I use the page builder timer across multiple pages?
No — timers created directly in the page builder are unique to that page. For reusable timers, use Marketing → Countdown Timers instead.

Q: Can I make the page builder timer repeat automatically?
Not currently. The built-in countdown element supports one fixed end time only.

Q: What happens when the timer expires?
It will follow your selected Expire Action — for example, redirect to another page, disappear, or display a message.
