Set Up Your Booking Calendar in Alvéya™

Updated June 2026
Back to Getting Started

https://youtu.be/nvd_Gi_29Do

Written Instructions

1. Access Calendar Settings 

  • Navigate to the ‘Calendars’ section.

  • Click on ‘Calendar Settings’.

2. Understand Appointment Types 

  • Recognize that calendars are commonly known as appointment times.

  • Note that a personal calendar appointment type is already available.

3. Create a New Appointment Type

  • Example: Set up a ‘Follow Up Consultation’.

  • Click on ‘New Calendar’ and then ‘Explore More Types’.

4. Choose Appointment Type 

  • Select ‘Service Booking’ for the appointment type.

5. Fill in Appointment Details 1:09

  • Enter the appointment title (e.g., ‘Follow Up Consultation’).

  • Add a description if desired.

6. Customize URL Slug 1:23

  • Note that a random slug is generated if a custom domain is not set.

  • Once a custom domain is added, the slug will be standard.

7. Set Booking Availability 1:55

  • Choose to use an existing availability schedule or create a custom one.

8. Advanced Settings 2:06

  • Add an image or logo for the appointment type.

  • Group calendars together if needed.

9. Configure Appointment Title and Location 2:26

  • Set the title for the calendar meeting.

  • Select the staff member and meeting location.

10. Set Meeting Priority 2:53

  • Choose the meeting platform (Zoom, Google Meet, etc.).

  • Enter the meeting link if applicable.

11. Define Availability and Booking Rules 3:06

  • Set custom hours or standard hours for availability.

  • Define booking rules such as duration, minimum scheduling notice, and buffer time.

12. Advanced Settings for Forms and Notifications 4:08

  • Set up intake forms (default or custom).

  • Configure consent and confirmation settings.

13. Payment and Widget Customization 4:52

  • Set up payment acceptance through management services.

  • Customize widget appearance to match brand colors.

14. Save the Appointment Type 5:04

  • Click ‘Save’ to finalize the appointment type.

15. Group Appointment Types 5:25

  • Create a new group (e.g., ‘Consultations’).

  • Add initial and follow-up appointments into the group.
