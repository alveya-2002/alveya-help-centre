Domain setup for client portal/courses &amp; funnels

Updated June 2026
Back to Courses & Funnels

This article is step one from the Domains playbook. To continue the process of setting up your domains after this step, head back to the playbook here.

Written step by step instructions and links to the templates for this video are below.

https://youtu.be/dkc--DzQwos

WRITTEN INSTRUCTIONS:

  • This guide outlines the steps to set up domains and URL redirects in the VEA system for client portals and funnels.

Key Steps

1. Access Domains and URL Redirects

  • Navigate to the Domains and URL Redirects section in VEA.

  • Confirm that you have existing sub-domains set up.

2. Set Up Client Portal Domain

  • Click on Connected Domain.

  • Enter Client Portal as the name, using the word Portal.

3. Add Domain Record for Client Portal

  • Click on Add Domain and then Add Record.

  • Choose CNAME as the record type.

  • Set the Host as your subdomain word and the Value as the client portal URL.

  • Copy the required value for later use.

4. Configure Domain Settings

  • Go to your domain settings.

  • Select CNAME and input your subdomain word.

  • Paste the copied value into the Value field.

5. Verify Domain Records

  • Return to VEA and click on Verify Records.

  • Wait approximately 30 seconds for verification.

6. Confirm Verification

  • Check for the Modify button indicating successful verification.

 

Set Up Domain for Funnels

  • Go back to Settings, then Domains and URLs.

  • Click on Connect to Domain for funnel setup.

1.Add Funnel Domain Record

  • Name the domain (e.g., Offers).

  • Click Add Record and choose CNAME.

  • Copy the subdomain value for your funnel.

2. Verify Funnel Domain Records

  • Return to VEA and click on Verify Records to confirm the funnel domain.

Additional Options

  • If needed, you can add domains for stores or websites later.

  • If a 404 page is not set up, you can return to select it later.

  • you can set up multiple sub domains for different funnels

Cautionary Notes

  • Ensure that the subdomain names are unique and not already in use.

  • Double-check the CNAME values to avoid misconfiguration.
