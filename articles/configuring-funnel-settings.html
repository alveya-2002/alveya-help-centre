Configuring Your Funnel Settings

Updated June 2026
Back to Courses & Funnels

This article is a step from the Funnels & Landing Page Playbook. To continue the process of setting up your funnel after this step, head back to the playbook here.

Written step by step instructions  for this video are below.

WRITTEN INSTRUCTIONS:

This video is a part of the full run through video above. If you have watched that already you may have done these steps already. If you specifically want to learn about funnel settings, continue watching.

There are three areas in Alvéya where funnel settings can be configured: the main funnel settings panel, the individual funnel step settings, and the SEO settings within the page builder. This guide walks through each one in the order you would complete them.

Area

What you configure here

Part 1 — Main Funnel Settings

Funnel name, URL path, domain, favicon, analytics tracking, chat widget, Facebook pixel events

Part 2 — Funnel Step Settings

Step name, URL slug, products (if selling), form redirect behaviour

Part 3 — SEO Settings

Page title, meta description, keywords, author, social sharing image, custom meta tags

Part 1 — Main Funnel Settings

These settings apply to the funnel as a whole. To access them, open the funnel and click Settings on the far right-hand side of the funnel builder.

Step Name and URL Path

At the top of the settings panel you can update the name of the funnel step or page, and the URL path.

  • The URL path is the link you will share — either by adding it as a button on your main website, or linking to it from an external website menu or navigation.

  • Update the path to something short and relevant to your opt-in (e.g. /gut-health-guide).

💡  Use lowercase letters and hyphens only — no spaces or special characters. This keeps your URL clean and easy to share.

Domain Name

This is where you connect your funnel domain so the page sits on your own branded URL rather than a default Alvéya address.

  • If you have already set up a funnel domain name, select it from the dropdown here.

  • If you have not yet set up a domain, refer to the domain setup tutorial first, then return to this step.

Favicon URL

The favicon is the small icon that appears in the browser tab. You can upload your own favicon through your Alvéya media storage and then link to it here.

  • Navigate to your media storage and upload your favicon image.

  • Once uploaded, click the three dots next to the file and select Get Link.

  • Copy that link and paste it into the Favicon URL field in the funnel settings.

💡  Use a square PNG image — ideally 512 x 512 pixels — with a transparent background for the best result across all browsers and devices.

Header Tracking Code

If you are using Google Analytics or any other header-based tracking script, paste the code into the heading tracking code field here.

  • For Google Analytics, copy the tracking code from your GA4 property and paste it in.

  • If you prefer to manage tracking through the Events tab (covered below), you do not need to add anything here.

Additional Settings to Check

Take a moment to review the remaining toggles and options in the settings panel:

  • Chat widget — if you would like a chat widget to appear on your funnel page, you can enable this here.

  • Review any other settings in the panel and turn them on or off based on your needs.

  • Click Save when you are done.

Events Tab — Facebook Pixel

If you are running Facebook or Meta ads and need to track pixel events (such as Lead or Purchase), this is where you configure them.

  • Click the Events tab within the funnel settings panel.

  • Add your Facebook pixel event details here so Alvéya fires the correct event when a visitor completes an action on your funnel page.

Statistics Tab

The Statistics tab gives you a live view of your funnel’s performance. You can see:

  • Page views — how many times each page has been visited.

  • Opt-ins — the number of form submissions.

  • Sales and earnings per page — if you are selling through the funnel, your revenue data will appear here.

⚠️  The Security tab is visible in the settings panel but is intended for developers only. You do not need to configure anything there.

 

Part 2 — Funnel Step Settings

Each individual page within a funnel (such as the opt-in page and the confirmation page) has its own settings. These are separate from the main funnel settings covered above.

To access a step’s settings, click on the step you want to configure within the funnel builder, then navigate to the Publishing tab.

Step Name

You can rename the individual funnel step here. This is an internal label — it is not visible to your audience, but it helps you identify each step clearly within the builder.

URL Slug

Each funnel step has its own unique URL slug. This does not need to be a carefully crafted public-facing URL, but you can update it here if you want to change it from the default template name.

💡  For the confirmation page, you can update its slug here too. Head to the confirmation step, click Publishing, and change the slug in the same way.

Products (If Selling Through the Funnel)

If you are selling something through your funnel — for example, a paid workshop or program — you need to add it as a product first before it will be available on the page.

  • Click Add Product within the step settings and follow the steps to set it up.

  • Once the product is added here, return to the funnel page editor and add an Order Form element to the page.

  • Alvéya links the product you added in the step settings to the order form element on the page automatically.

💡  You do not need to configure this for a standard opt-in funnel where no payment is involved. This step is only relevant if you are collecting payment as part of the funnel.

Form Redirect — Setting the Next Step

This is one of the most important settings to check before publishing. It controls what happens after someone fills in and submits the opt-in form.

There are two places where this redirect can be set:

Option 1 — Within the funnel page editor: Click on the form element on the page. In the form settings, look for the Redirection field. Set this to Go to Next Step. This tells Alvéya to automatically take the visitor to the confirmation page once they submit.

Option 2 — Within the form builder: If you select Use Action from Form Builder in the redirection setting, the redirect will instead be controlled by the Next Step setting inside the form builder itself.

⚠️  For opt-in funnels inside Alvéya, always set the redirect to Go to Next Step. This ensures the visitor is taken to your confirmation page after submitting the form, rather than staying on the same page or going somewhere unexpected.

Adding or Reordering Funnel Steps

If you want to expand your funnel — for example, adding a sales page after the opt-in — you can do this within the funnel builder:

  • Click Add New Page to add a new step to the funnel.

  • You can duplicate an existing step if you want to use a similar layout as a starting point.

  • Steps can be dragged up or down to change the order in which they appear in the funnel flow.

 

Part 3 — SEO and Search Settings

SEO settings control how your funnel page appears in Google search results and how it looks when shared on social media. These are configured from within the funnel page editor.

To access them, open the opt-in page in the editor and click on SEO and AI Search Optimisation.

Page Title

The page title is what appears as the clickable heading in Google search results and in the browser tab.

  • Aim for between 50 and 60 characters in total.

  • Include relevant keywords and phrases that your ideal client is likely to search for.

  • Make it clear and descriptive — the title should tell someone exactly what they will find on the page.

Meta Description

The meta description is the short summary that appears beneath the page title in search results.

  • Aim for between 150 and 160 characters.

  • Use natural language and include keywords and phrases your ideal client would use to find your offer.

  • Focus on the benefit — what will they get, and why is it relevant to them?

Keywords

Add relevant keywords in the Keywords field. These are additional signals to search engines about what your page is about. Use the same terms and phrases you have woven into your title and description.

Author Name

Add your name in the Author field. This is a standard SEO field and helps attribute the content to you as the creator.

Social Sharing Image

This is the image that appears when someone shares your funnel page link on Facebook, Instagram, or other social platforms — also known as an Open Graph (OG) image.

  • Design your image in Canva before uploading it here.

  • Create a square image and place your main content — text, branding, and visuals — through the centre of the image.

  • Keeping the key content centred ensures it displays correctly across different platforms and devices, which crop the image differently.

  • Once uploaded, Alvéya will show you a preview of how it will appear when shared.

💡  Always upload a custom social sharing image before sharing your funnel link anywhere. A branded image with a clear headline will significantly improve how often people click through from social media.

Custom Meta Tags and Links

There is also a field for custom meta tags and links if you need to add any advanced code here. If you are not sure what this is for, refer to the Alvéya knowledge base help article for guidance.

Repeat for the Confirmation Page

Once you have completed the SEO settings for the opt-in page, switch to the confirmation page within the same builder and fill in the same SEO fields there too. Each page in the funnel has its own SEO settings that need to be configured separately.

 

Final Checklist Before Publishing

✅

Main funnel settings saved — name, URL path, domain, and favicon configured.

✅

Tracking codes added if using Google Analytics or Meta Pixel.

✅

Funnel step names and slugs updated.

✅

Form redirect set to Go to Next Step on both the opt-in page and confirmation page.

✅

SEO title and meta description filled in on the opt-in page (50–60 and 150–160 characters).

✅

Social sharing image uploaded — square, key content centred.

✅

Author name and keywords added.

✅

SEO settings also completed on the confirmation page.

✅

Page published and front-end reviewed to confirm everything looks correct.

 

Once all settings are configured and your page is published, your funnel is ready to share with your audience.

If you get stuck at any point, reach out via live chat or submit a support request and we will guide you through the process.
