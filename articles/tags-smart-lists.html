Tags &amp; Smart Lists

Updated June 2026
Back to CRM & Contacts

Organise, segment and automate your CRM with precision.

 This guide is ideal if you want to:

  • Organise your contacts using structured tags

  • Automatically apply tags using workflows and triggers

  • Create dynamic Smart Lists based on behaviour and criteria

  • Keep your CRM clean, searchable and easy to segment

Tags and Smart Lists form the foundation of a well-structured CRM. When set up correctly, they reduce manual sorting and allow your automation systems to work intelligently behind the scenes.

Understanding Tags

Tags are digital labels attached to contact profiles.

They allow you to:

  • Categorise contacts

  • Track behaviours

  • Trigger automations

  • Segment audiences for marketing

Think of tags as meaningful markers that answer the question:

“What has this person done?”

For example:

  • Attended a workshop

  • Purchased a program

  • Submitted an application

  • Opted into a free guide

  • Booked a consultation

Tags are not just organisational tools. They are automation triggers and segmentation tools.

Best Practice Tag Structure

We recommend naming tags clearly and consistently.

Examples:

  • booked: discovery call

  • cancelled: discovery call

  • attended: discovery call

  • purchased: hormone program

  • opt in: gut guide

  • opt in: newsletter

  • submitted: contact form

  • submitted: practitioner application

Using a consistent format keeps your CRM readable and scalable.

How To Tag Contacts Manually

Manual tagging is useful when cleaning data or updating individual records.

To tag a single contact:

  1. Go to Contacts

  2. Open the contact profile

  3. Locate the Tags area

  4. Add a new tag or select an existing one

  5. Save

To tag multiple contacts at once:

  1. Go to Contacts

  2. Select multiple contacts using the checkboxes

  3. Click the Add Tag option in the toolbar

  4. Choose or create a tag

  5. Apply

Bulk tagging is helpful when:

  • Importing contacts

  • Cleaning old lists

  • Assigning campaign groups

How To Tag Contacts Automatically

Automation is where tagging becomes powerful.

You can automatically apply tags when a contact:

  • Books an appointment

  • Cancels an appointment

  • Attends an appointment

  • Submits a form

  • Purchases a product

  • Joins a community

  • Opts into a free resource

To apply tags automatically:

  1. Go to Automation → Workflows

  2. Create a new workflow (or edit an existing one)

  3. Choose your trigger (e.g. appointment booked)

  4. Add an action: Add Contact Tag

  5. Select or create the tag

  6. Save and publish

Tags can also be used as triggers themselves.

For example:

  • If tag added = opt out

  • Then disable marketing communication

This creates protective automation systems inside your CRM.

Smart Lists

Step 1 – Understanding Smart Lists

Smart Lists are dynamic segments.

They automatically update based on filters and rules.

For example:

  • All contacts with tag “opt in: webinar”

  • All contacts who booked an appointment in the last 30 days

  • All contacts without a tag

  • All contacts in a specific pipeline stage

Unlike static lists, Smart Lists refresh automatically.

Step 2 – How To Create a Smart List

  1. Go to Contacts

  2. Click Add Smart List

  3. Click Advanced Filters

  4. Choose your filter type (e.g. Tag)

  5. Define the rule (e.g. is, is not, contains)

  6. Select the specific tag or criteria

  7. Apply

  8. Name your Smart List

  9. Save

You can combine multiple filters for more advanced segmentation.

Example:
Tag is “opt in: webinar”
AND
Appointment status is “No Show”

This level of segmentation allows targeted follow-up.

Step 3 – Sharing Smart Lists (Optional)

If working with a team:

  1. Open your Smart List

  2. Access list settings

  3. Adjust sharing permissions

  4. Select users to share with

  5. Save

This ensures everyone works from the same segmented view.

Sending Emails to Segmented Audiences

Tags and Smart Lists are used when selecting email recipients.

When creating a campaign:

  1. Go to Marketing → Email

  2. Create a new campaign

  3. Choose recipients

  4. Select:

    • A Smart List

    • Specific tags

    • Pre-built engagement segments

    • Individual contacts

This ensures relevant messaging to the right group.

Keeping Your CRM Clean

To maintain clarity:

  • Use consistent naming conventions

  • Avoid duplicate tag variations

  • Merge duplicates regularly

  • Audit unused tags quarterly

A structured tag system prevents automation conflicts and reporting errors.

Frequently Asked Questions

Where can I manage or delete tags?

Go to Settings → Tags to manage all tags in your account

How do I quickly find contacts with a specific tag?

Go to Contacts → Advanced FIlters → Type in “Tags” → Select “tags from the list → Adjust the filters → Click Apply

Can I bulk remove a tag?

Yes. Filter by the tag first, → select contacts in bulk, → select more → and remove the tag from the toolbar.

Can I see what tags a contact has?

Yes. Open the contact profile and view the Tags section.

Can tags trigger automations?

Yes. Tags can act as workflow triggers, making them central to your automation logic.
